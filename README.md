# Humanitarian-Impacts-of-Natural-Disasters
This research project uses a global country-year panel of EM-DAT natural disasters (1980–2022) with two-way fixed effects, population-standardized outcomes, and type stratification to test whether rising disaster frequency produces proportionally greater humanitarian burdens. Results show elasticities of deaths and affected populations with respect to event frequency are consistently and significantly below one, indicating that more frequent disasters do not generate proportionally larger mortality or impact burdens once country and year effects are accounted for.
